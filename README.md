# 건어물 쇼핑몰
건어물 상품을 조회하고 관리할 수 있는 온라인 쇼핑몰 프로젝트입니다.

## 프로젝트 소개
온라인에서 다양한 건어물 상품을 편리하게 확인할 수 있도록 제작한 쇼핑몰 웹사이트입니다.

## 기술 스택
- Java
- Spring Boot
- HTML / CSS / JavaScript
- Oracle
- Git / GitHub
